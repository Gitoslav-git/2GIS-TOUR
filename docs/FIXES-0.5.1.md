# Проверка версии 0.5.1

- Не более 5 операций построения, изменения или поиска за 60 секунд для одной гостевой сессии.
- Каждый запрос геопозиции получает новые координаты, а не двухминутный кэш.
- Координаты вне выбранного города не отправляются в маршрут.
- Автоматический маршрут отбрасывает ритуальные и иные нерелевантные сервисы.
- Для проверки добавлена Москва.

VPN не меняет GPS. В Android Emulator откройте `…` → `Location`, задайте точку города,
нажмите `Send`, а затем `Обновить геопозицию` в приложении. Для Москвы можно использовать
`55.7558, 37.6173`.

Шестая дорогая операция за минуту должна вернуть понятное сообщение с временем ожидания.
