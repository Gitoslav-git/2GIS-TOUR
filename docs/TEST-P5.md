# P5: ручная проверка безопасного офлайн-просмотра

## Подготовка

1. Запустите backend с отдельной тестовой SQLite-базой:

   ```powershell
   $env:GULYAY_DB_PATH = "$env:TEMP\gulyay-p5-test.sqlite3"
   $env:GULYAY_ROUTE_RETENTION_MINUTES = "1440"
   python -m uvicorn gulyay.api:app --app-dir backend --host 0.0.0.0 --port 8000
   ```

2. Установите debug APK и откройте приложение при доступном backend.
3. При ошибке собирайте Logcat:

   ```powershell
   adb logcat -v brief GulyayNetwork:I GulyayMapMemory:I AndroidRuntime:E *:S
   ```

## Сохранение и офлайн-просмотр

1. Создайте маршрут и откройте карту один раз при доступном backend.
2. Вернитесь на главный экран. Отключите сеть эмулятора в Extended Controls
   или остановите backend.
3. Нажмите карточку текущего маршрута, чтобы открыть карту.

Ожидаемый результат: показываются сохранённые точки, порядок, длительность и, если SDK
сможет её отрисовать, сохранённая геометрия. Экран сообщает, что это сохранённая версия
без соединения. Если 2GIS-карта не загрузилась, остаётся список точек и fallback карты.

## Ограничения офлайн-режима

На экране сохранённого маршрута убедитесь, что нет действий запуска, паузы, продолжения,
остановки, редактирования точек или запроса. Вернитесь в приложение и откройте историю:
удаление по backend при выключенной сети должно закончиться сообщением об ошибке, не
исчезновением карточки.

Ожидаемый результат: офлайн-просмотр не отправляет действия прогулки, позиции,
перестроения или удаления на backend.

## Перезапуск процесса и восстановление сети

1. Не включая сеть, завершите процесс приложения через Android Studio или:

   ```powershell
   adb shell am force-stop ru.gulyay.app
   ```

2. Откройте приложение и маршрут снова.
3. Включите сеть/backend, вернитесь на главный экран и повторите синхронизацию карточки.

Ожидаемый результат: в пределах 24 часов текущей загрузки snapshot остаётся доступен
после завершения процесса. После сети backend подтверждает существование, версию и статус;
только затем становятся доступны серверные действия.

## Retention и безопасная граница

Snapshot не продлевается просмотром. Для безопасной автоматической проверки 24 часов
используйте отдельную SQLite-базу и тесты, не меняя время или данные рабочей базы:

```powershell
$env:PYTHONPATH = (Join-Path $PWD 'backend')
python -m pytest backend/tests/test_repository.py -q
```

Ожидаемый результат: обычный маршрут удаляется согласно retention; `ACTIVE` и `PAUSED`
сохраняются по отдельной серверной политике. После перезагрузки самого устройства или
истечения 24-часового монотонного окна snapshot нельзя открыть без backend: это защищает
от бессрочного гостевого офлайн-архива и неверных часов устройства.
