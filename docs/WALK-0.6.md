# Прохождение маршрута в версии 0.6

## Ограничение пеших переходов

LLM возвращает `maxWalkingMinutes`, но backend дополнительно разбирает распространённые русские формулировки независимо от ответа модели:

- «желательно, чтобы до локаций идти было недалеко» → 20 минут;
- «короткие переходы», «места рядом», «меньше ходить» → 20 минут;
- «между точками максимум 15–20 минут» → 20 минут;
- «не больше 12 минут пешком» → 12 минут.

Пожелание о ходьбе не считается районом, направлением или стартом. Перед Routing API слишком далёкие кандидаты отбрасываются по прямой дистанции с консервативным запасом. После получения реального участка его `durationSeconds` обязательно проверяется; превышающий лимит участок не публикуется. При ручной перестановке лимит проверяется повторно.

## API прохождения

### Начало

`POST /v1/routes/{routeId}/walks`

```json
{"routeVersion": 3}
```

Возвращается `WalkSession` со статусом `ACTIVE`, первой текущей точкой и расчётным остатком. Для одной гостевой сессии одновременно допускается одно активное или приостановленное прохождение. Повторный запуск той же версии возвращает существующий `walkId`.

### Геопозиция

`POST /v1/walks/{walkId}/positions`

```json
{
  "lat": 54.1961,
  "lon": 37.6189,
  "accuracyMeters": 18,
  "measuredAt": "2026-09-16T12:00:00Z"
}
```

Точка достигнута только после двух последовательных измерений в радиусе 75 м, с точностью не хуже 50 м и интервалом не менее 5 секунд. Устаревшее измерение не создаёт повторный `Visit`. Backend сохраняет время достижения, но не сохраняет непрерывный трек координат.

Остаток времени вычисляется по фактически прошедшему активному времени от начала прогулки. Поэтому более долгое пребывание на локации уменьшает остаток; время паузы из расчёта исключается.

### Управление

`POST /v1/walks/{walkId}/actions` принимает `PAUSE`, `RESUME` или `STOP`. На паузе Android прекращает отправку позиции. Последняя достигнутая точка автоматически переводит прохождение в `COMPLETED`. Кнопка «Назад» закрывает карту без остановки; на главном экране остаётся «Продолжить прогулку».

## Проверка

1. Построить маршрут и нажать **«Начать прогулку»**.
2. В эмуляторе задать координату первой точки. Одного измерения недостаточно; после второго точного измерения не ранее чем через 5 секунд должна открыться следующая точка.
3. Проверить, что остаток времени уменьшается по фактическому времени.
4. Нажать **«Пауза»**: позиция не должна отправляться. После **«Продолжить»** прохождение идёт с той же точки.
5. Закрыть карту кнопкой **«Назад»**: на главном экране должна быть кнопка **«Продолжить прогулку»**.
6. Дойти до последней точки либо нажать **«Завершить»**: активная прогулка закрывается.
