# Проверка версии 0.5.2

- При запуске приложение запрашивает разрешение и пытается определить город автоматически.
- Проверяется последняя системная позиция, затем параллельно запрашиваются свежие данные GPS и сети.
- Координаты Москвы больше не сравниваются с Тулой, выбранной по умолчанию.
- Доступны Тула, Владимир и Москва.
- Если координаты не получены или находятся вне этих зон, выбран пункт `Локация не определена`.
- В этом состоянии пользователь открывает тот же список и вручную выбирает город.
- Кнопка `Использовать без геопозиции` удалена.
- Вводить координаты вручную не требуется.
