# Сохранение маршрута и временной бюджет в версии 0.4.1

## Причина исправления

В 0.4 `Route`, владелец и исходный `CreateRoute` находились в словарях процесса Python. После перезапуска backend Android продолжал показывать сохранённый экран, но `POST /v1/routes/{id}/revisions` получал `NOT_FOUND`. Версия 0.4.1 делает SQLite авторитетным хранилищем для API-07 и API-08.

## Хранение и атомарное изменение

По умолчанию база создаётся в `backend/data/gulyay.sqlite3`. Путь можно изменить переменной `GULYAY_DB_PATH`; файл базы и служебные WAL-файлы исключены из Git. Таблица `routes` хранит `routeId`, гостевую сессию владельца, текущий `routeVersion`, JSON маршрута и JSON исходного запроса. Начиная с 0.4.2 таблица `route_versions` дополнительно хранит неизменяемый снимок каждой успешно принятой версии для будущих активных прогулок и истории. Гостевые записи и их снимки автоматически очищаются через 24 часа; значение настраивается `GULYAY_ROUTE_RETENTION_HOURS`. Срок 24 часа остаётся проектным решением до ответа по `DATA-01`.

Создание маршрута сохраняет запись до успешного ответа клиенту. Изменение сначала читает текущую версию и владельца, полностью строит новый маршрут, затем выполняет условный `UPDATE ... WHERE routeVersion = baseVersion`. Если параллельное изменение уже победило, возвращается `VERSION_CONFLICT`; если INTENT, GEO или проверка бюджета завершились ошибкой, запись не меняется.

Android сохраняет `routeId`, `routeVersion`, город, текст и последнюю сводку в приватных настройках приложения. Маршрут восстанавливается после закрытия приложения. Для перехода со старой 0.4 предусмотрена одноразовая страховка: `NOT_FOUND` при изменении запускает обычное создание по новому тексту и явно сообщает, что создан новый маршрут.

## Запрошенное и фактическое время

`Route` возвращает:

- `requestedMinutes` — распознанный запрос пользователя;
- `totalMinutes` — сумма фактических переходов 2ГИС и оценок посещения;
- `unusedMinutes` — неиспользованный остаток.

Для общего запроса Places ищет достопримечательности, парки и скверы, а также памятники, чтобы закрытые вечером музеи не оставляли маршрут из одной точки. ROUTE рассматривает не больше десяти кандидатов и восьми итоговых точек, прекращая подбор после достижения 90% бюджета. Ни закрытые места, ни маршруты без реального пешего пути не публикуются. Если остаток превышает 20 минут и 15% запроса, пользователь получает объяснение, а не ложное увеличение времени посещения.
