# Путь к MVP 1.0

Каждый этап должен иметь тег `v0.x`, зелёные проверки backend и Android и установочный APK в артефактах GitHub Actions. Версии `0.x` — промежуточные срезы разработки полного 1.0.

Эвристика автоматической генерации не объявляется математически оптимальным маршрутом; точная оптимизация остаётся обязательной до 1.0.
