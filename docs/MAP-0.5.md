# Карта и геопозиция в версии 0.5

## Граница этапа

Версия 0.5 добавляет встроенную карту Android Map SDK 2ГИС и одноразовое получение текущей геопозиции. Прохождение маршрута, фоновые обновления, пауза и автоматическое прибытие на расстоянии 75 метров относятся к версии 0.6 и здесь не имитируются.

Карта строится только по сохранённому ответу backend:

- маркеры получают `lat`/`lon` из `points` API-06/API-07;
- зелёная линия объединяет `geometry` всех `legs`, ранее полученную backend от Routing API 2ГИС;
- при наличии разрешения отдельный маркер показывает старт пользователя;
- без разрешения маршрут остаётся рабочим, а backend явно отмечает приблизительный старт.

Android не подменяет отсутствующую геометрию прямыми линиями. Если backend не вернул как минимум две координаты, на экране показано «геометрия пути отсутствует».

## Геопозиция

Приложение запрашивает `ACCESS_COARSE_LOCATION` и `ACCESS_FINE_LOCATION` только после нажатия «Определить геопозицию». Свежая последняя позиция принимается не старше двух минут; иначе выполняется одно обновление с тайм-аутом 12 секунд. В API-06 отправляются `lat`, `lon` и фактическая `accuracyMeters`. Координаты и точность сохраняются локально вместе с текущим маршрутом и удаляются кнопкой «Сбросить геопозицию».

Если пользователь определил или сбросил позицию после построения, следующий запуск расчёта создаёт новый маршрут от нового старта, а не маскирует изменение обычной текстовой ревизией. При неудаче прежний маршрут остаётся доступен.

## Поворот и восстановление

Главный экран сохраняет город, запрос, текущий маршрут, версию, результат и геопозицию. Экран карты хранит разобранный маршрут в Android `ViewModel`, поэтому при повороте не повторяет запрос к backend. `MapView` подключён к lifecycle и имеет стабильный view ID; восстановленная позиция камеры не перезаписывается автоматическим центрированием.

## Ключ и воспроизводимость

Android SDK зафиксирован переменной `DGIS_SDK_VERSION`, значение по умолчанию — `13.6.0`. Файл мобильного ключа должен называться `dgissdk.key` и попадать в `app/src/main/assets` только во время локальной сборки либо из секрета GitHub Actions `DGIS_SDK_KEY_BASE64`. Файл ключа исключён из Git.

Если ключ отсутствует или не принят SDK, приложение не падает: экран карты объясняет, что нужно проверить ключ и подписку. Серверные ключи Places/Routing и `OPENAI_API_KEY` по-прежнему принадлежат только backend.

## Открытый вопрос

Право на SDK, мобильный ключ и тариф остаются `SDK-01`. Текст отдельного согласия на диагностическую статистику не определён (`CONSENT-01`), поэтому 0.5 инициализирует SDK с отказом от её сбора.
