# Проверка версии 0.5.3

Контрольный запрос для Москвы:

`Хочу погулять от МЦК Кутузовская в сторону центра 2 часа, желательно чтобы до локаций идти было недалеко.`

Ожидаемый разбор:

- `startLocationHint`: `МЦК Кутузовская`;
- `directionHint`: `центр`;
- `locationHint`: `null`;
- `centerOnly`: `false`;
- `preferShortWalks`: `true`.

Backend разрешает стартовый ориентир через Places API 2ГИС, ищет туристические места вокруг старта, отдаёт предпочтение коротким переходам и продвижению в указанную сторону. Первый переход Routing API начинается от координат найденного ориентира, а не от центра Москвы.

Запрос `от офиса на Кутузе` неоднозначен без названия или адреса. Приложение должно попросить уточнить старт, а не выбрать случайный офис.

Логику геопозиции Android в этой версии не меняли.
