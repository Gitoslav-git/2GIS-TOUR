# Путь к MVP 1.0

Каждый этап должен иметь тег `v0.x`, зелёные проверки backend и Android и установочный APK в артефактах GitHub Actions. Версии `0.x` — промежуточные срезы разработки полного 1.0.

| Версия | Проверяемая граница | Статус |
| --- | --- | --- |
| 0.1 | Java Android UI, выбор Тулы/Владимира, ввод запроса, устойчивость ввода к повороту, HTTPS-клиент, каркас backend, контракт ошибок, тесты, CI APK. | Собрана в GitHub Actions и запущена на эмуляторе; backend не был подключён к APK. |
| 0.2 | LLM разбор в структурированные поля, уточнение города/длительности, проверка некорректного ответа, безопасное хранение ключа backend; отладочная связь с локальным backend эмулятора. | Проверена заказчиком на Android Emulator; выявлен и исправлен пропуск пожелания «в центре». |
| 0.3 | Реальные Places и Routing API 2ГИС; проверка часов, длительностей и достижимости; интеграционные проверки Тулы и Владимира. | Код и изолированные проверки готовы; живая интеграционная проверка ожидает серверные ключи Places и Routing. |
| 0.4 | Подбор оптимального порядка по проверенным пешим участкам и бюджету; пересчёт текста с атомарной версией, редактирование точек. | Ожидает реализации. |
| 0.5 | Встроенная карта 2ГИС, геопозиция, состояние при повороте; маршрут и точки по серверным координатам/геометрии. | Ожидает мобильного SDK и реализации. |
| 0.6 | Прохождение, пауза, фактическое время посещения, обновление остатка и дедупликация геопозиции; N = 75 м по согласованию и дополнительные проверки `DEC-08`. | Ожидает реализации. |
| 0.7 | Партнёрские предложения по согласованному источнику и правилу выбора. | Ожидает решения владельца продукта и реализации. |
| 0.8 | Вход по телефону/почте, профиль, история, разрешения и выход в соответствии с аналитикой. | Ожидает провайдера доставки и реализации. |
| 1.0 | Полный сквозной процесс из бизнес-требований и аналитики; реальные интеграционные и инструментальные тесты; исправленные ошибки; выпущенный APK. | Не выпущена. |

Не переименовывать текущий этап в `1.0`. Сборка 0.3 считается интеграционно подтверждённой только после живой проверки Places и Routing для Тулы и Владимира.
