# Проверка разбора запроса в версии 0.2

`POST /v1/routes/interpret` — временная проверяемая граница этапа 0.2. Нормативный `API-06 POST /v1/routes` из системной аналитики после подключения GEO должен строить и сохранять маршрут; этот тестовый endpoint ничего не сохраняет и не возвращает мест или координат.

Запрос: `Content-Type: application/json`, `X-Device-Session: <UUID>`, `X-Request-Id: <UUID>`; тело соответствует `CreateRoute`: `cityId` (`tula` или `vladimir`), `query` (3–1000 символов), `filters` (включая необязательный `durationMinutes` в диапазоне 30–720), `deviceSessionId` (совпадает с заголовком). Например:

```json
{"cityId":"tula","query":"Хочу гулять по храмам 2 часа и зайти поесть","filters":{},"deviceSessionId":"<тот же UUID>"}
```

Успешный ответ 200:

```json
{"cityId":"tula","durationMinutes":120,"durationSource":"text","interests":["храмы"],"includeFood":true,"withChildren":false,"unusualPlaces":false,"centerOnly":true,"locationHint":"центр","warnings":[]}
```

`durationSource` — `text`, `filter` или `default`; время по умолчанию 180 минут и сопровождается предупреждением. Выбранный фильтр имеет приоритет перед текстом. Для обязательного выбранного города и недопустимой длительности ответ `QUERY_NEEDS_CLARIFICATION` (422) содержит `details.fields` с `cityId` или `durationMinutes`. Выбранный город обязателен; отсутствие длительности в тексте допустимо при значении по умолчанию.

`centerOnly=true` сохранён для совместимости этапов, если пользователь написал «в центре» или «по центру». Начиная с 0.4 универсальное поле `locationHint` также переносит стороны города, районы и ориентиры; разрешённая через GEO область возвращается в `Route.searchArea`.

Все ошибки имеют вид `{"error":{"code":"...","message":"...","details":{},"requestId":"..."}}`. `VALIDATION_ERROR` (400) — ошибочное тело или город, `UNAUTHORIZED` (401) — отсутствие совпадающей гостевой сессии, `LLM_AUTH_ERROR` (503) — неверный ключ или права, `LLM_UNAVAILABLE` (503) — не задан ключ/модель либо недоступен сервис, `LLM_INVALID_RESPONSE` (502) — ответ не прошёл структурную проверку. Секреты или сырой ответ провайдера в теле ошибки не возвращаются.

Поле `interests` содержит лишь категории пожеланий. Модель не создаёт `placeId`, расписание, пешую геометрию и координаты — их сможет поставлять только 2ГИС после этапа 0.3. Нельзя считать успешный разбор успешным построением маршрута.
